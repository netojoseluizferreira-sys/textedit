# TextEdit — Editor de Texto em Terminal

Um editor minimalista inspirado no Vim, construído do zero com estruturas de dados nativas.

## Como Rodar
1. Clone o repositório.
2. Instale as dependências: `pip install -r requirements.txt`
3. Execute: `python main.py`

## Arquitetura
- **Front-end:** Interface em `curses` (renderização e captura de teclas).
- **Back-end:** Estruturas de dados lineares (Lista duplamente encadeada e Pilhas).
